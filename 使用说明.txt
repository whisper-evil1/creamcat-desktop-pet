星宠语 · 桌面宠物 v7（多宠物）
==========================
项目说明见 README.md

启动
  双击「启动桌宠.bat」。默认启动 config.json 里记录的那只（出厂是星狐）。
  想指定别的：py -3 pet_app.py --pet naitang

已有宠物
  星狐（xinghu）· 奶糖 粉白小猫（naitang）· 团团 卷毛绵羊（tuantuan）
  布丁 奶油卷毛泰迪（buding）· 可可 圆滚滚仓鼠（keke）

操作
  · 换宠物：右键 -> 「换一只宠物」。会记住选择，下次启动还是它。
  · 拖拽：在身上长按 0.35 秒即可拖动（不用双击）；松手落地。
      - 命中判定按角色真实轮廓，点旁边透明区域不会误抓。
      - 拖动时有磁吸感（约 22px 内自动贴边），松手再精确吸附一次（约 34px）。
      - 会吸附到屏幕边、其它窗口的标题栏上沿/下沿、左右边框、任务栏上沿，刚好站上去。
      - 拖到屏幕左/右边缘会按"角色身体"计算探头比例，最多一半身子探出屏幕外，
        脸和眼睛始终留在屏幕内；上边缘同样可以探头，不会被拖丢。
  · 唤醒：睡觉时单击 -> 唤醒。休眠态双击无效，不会乱走。
  · 走过去：双击桌面空白处 -> 朝那个位置走过去（单击空白不触发，防打字误触）：
      - 目标在上方：展开白羽翼飞过去，翅膀收拢 -> 肘部弯曲半展 -> 全展 -> 下压 连续扇动。
      - 同一水平线附近：侧面四足交替小跑（4 帧真实步态，左右换向）。
      - 目标在下方：直接撑开降落伞缓缓飘到目标点，不再倒着走。
      - 到达目标后会再贴一次最近的边框，刚好停在窗口边沿上。
  · 降落伞：拖到高处再松手 -> 3D 粉伞先膨胀张开，再缓缓飘回屏幕底部。
      - 九只用的是同一版式：伞顶固定在头顶上方、四帧里伞往下张开、吊绳跟着变短，
        和星狐那套手绘伞一致（星狐本身就是手绘 5 帧，其余八只是共享伞面 + 站立姿态合成）。
      - 伞面大小按各自身体宽度自动配（布丁耳朵宽、可可身子圆，伞都比身体宽一点才协调）。
  · 对话气泡：圆角暖白气泡 + 下方小尾巴指向头顶，每个宠物有自己的台词。
  · 休眠：趴睡时头顶连续冒出云朵泡泡（最多同时 4 个，大小位置各不相同），
      每个都由小到大鼓起、一边上飘一边散掉。
  · 清醒态单击完全无反应——你在别的窗口打字、点击时不会误触发。
  · 聊聊天（语音）：右键 -> 「聊聊天…」弹出输入框，打字回车发送，宠物用温柔女声念出回复。
      - 说「我叫小满」它会记住，之后会叫你名字；问「你是谁」「你饿不饿」「摸摸你」都能接。
      - 语音首次需联网合成，之后同一句话走本地缓存、不再联网；断网时只显示气泡、不报错。
      - 首次使用先装一次：py -3 -m pip install edge-tts
  · 右键菜单：
      聊聊天… / 说句话 / 睡一会儿 / 陪我走走
      回到主界面 / 去星穹展厅 / 换一只宠物
      显示在其他应用上层 / 拜拜（退出）
    如果菜单里只有前三条，说明还在用旧进程：右键「拜拜」后重新双击“启动桌宠.bat”。
  · 单形态：醒着只有坐姿一个形态，睡着只有趴睡一个形态，都不来回变形。
  · 长时间（默认 60 秒）不操作 -> 自动进入睡觉模式。

技术说明
  · Python 3.14（py -3）+ tkinter + Pillow，无需额外安装依赖。
  · 多宠物包：每只在 assets/pets/<id>/ 下有自己的 source（AI 图集）与 frames（动作帧）。
  · 素材：每只 3 张 AI 图集（姿态 4 格 / 侧面跑 4 格 / 扇翅 4 格）+ 原始立绘，
    切出 27 帧动作（星狐为 31 帧，含 5 帧手绘伞）。
  · 多帧统一 bbox 缩放（宽幅姿态改按宽度缩放），避免张开时忽大忽小、趴睡被裁。
  · 醒/睡/落地为单帧定格；门禁对定格状态按 manifest 声明豁免。

重建 / 校验
  · 重新生成帧：  py -3 build_assets.py            （构建全部宠物）
                  py -3 build_assets.py naitang    （只构建一只）
  · 门禁校验：    py -3 gate_check.py              （逐包检查）
  · 逻辑自检：    py -3 selftest.py                （64 项）
  · 帧对照图：    py -3 tools/preview_frames.py    （输出到 docs/frames/）
  · AI 图集在 assets/pets/<id>/source/，替换后运行 build_assets.py 重建。

新增宠物
  1. 生成 3 张图集：poses_2x2（站立/趴睡/被拎起/挥手）、run_2x2（严格侧面朝右四足跑）、
     wing_2x2（收拢/半展/全展/下压），外加一张 original.webp。
  2. 放进 assets/pets/<新id>/source/，在 pets.json 里照抄一条。
  3. build_assets.py <新id> -> gate_check.py <新id> -> selftest.py。

可调参数（pet_app.py 顶部）
  · LONG_PRESS_SEC：长按多久触发拖拽（默认 0.35 秒）。
  · DOUBLE_GAP / DOUBLE_DIST：双击空白的间隔与距离判定。
  · IDLE_SLEEP_SEC：多久不操作进入睡觉（默认 60 秒）。
  · FLY_HEIGHT：高于/低于多少像素分别判定为飞行/开伞（默认 70）。
  · PARACHUTE_SPEED / WALK_SPEED / FLY_SPEED：移动速度。
  · SNAP_DIST / SNAP_LIVE：松手吸附距离（34px）/ 拖动中磁吸距离（22px）。
  · EDGE_PEEK：探头时允许角色身体探出屏幕的比例（默认 0.5，即露一半）。
  · PUFF_MAX / PUFF_SPAWN / PUFF_LIFE：休眠泡泡的同屏数量、冒出间隔、单个寿命。

已知限制
  · 仅 Windows（透明窗口依赖 Windows 特性）。
  · 鼠标点击监听用轮询实现（每 30ms 检测一次），极端快速点击可能漏检。
  · 奶糖/团团/布丁/可可 的降落伞是"共享伞面 + 站立姿态"合成，伞面与星狐同款风格，但吊绳是程序画的，不如手绘的柔和。
  · 合成伞的伞面是通用款（珊瑚粉），不跟随每只宠物的配色。

【主界面：2D 小窝】★ 平时最常用的就是这一页
  · 双击“打开2D小窝.bat”，或在桌宠上右键 -> 回到主界面（2D 小窝）。
  · 第一屏是整间屋子，有六样东西可以点：床、猫爬架、猫窝、桌子、书柜、窗边。
  · 鼠标移上去，家具会亮起来，上面浮出名字；点一下就“切”到那件家具的近景
    （不是把整张图放大，是另外一张画好的近景，会柔和地淡入切过去），
    宠物跟着走过去，底部对话框升起，它开始说那里的事。
  · 对话框下面有三个选项气泡，点一个就接着聊；它会顺着上一个话题问下去。
  · 点右下角的爪印，可以展开输入框自己打字（回车发送）。
  · 试几句：“你饿不饿”“这里是什么地方”“带我去床边”“我叫小满”。
    告诉它名字之后，它会一直记着，道别时会叫你。
  · 左上角点心形可以摸它，心情条会涨，语气也会变。
  · 右上角 ⋯ 里有：星穹展厅 / 3D 小屋 / 宠物图鉴 / 换一只伙伴。
  · 想回全景：点任意空白处，或按 Esc。

【宠物图鉴（原主界面）】
  · 双击“打开星宠语主界面.bat”，或在桌宠上右键 -> 回到主界面。
  · 顶上导航：首页 / 宠物图鉴 / 宠物小屋 / 好友社区。
  · 五个场景（花海晴空 / 云端书桌 / 暖阳卧室 / 樱花草原 / 月夜城堡），
    右上角可以切白天 / 夜晚，点场景卡换地方。
  · 「换一只伙伴」在心情条右侧；宠物图鉴里每只都可以「带回小屋」。
  · 右侧面板：聊天（回车发送）/ 穿搭（挂件）/ 喂食（涨饱食度）/ 状态（三条进度）。
  · 舞台右下角「✦ 星穹展厅」可以去 3D 展台。

【网页打不开怎么办】
  · 先双击“检查打开环境.bat”，看它列出的浏览器和页面是否都在。
  · 三个网页用同样的方式打开：
        python open_page.py room3d/index.html      （3D 小屋）
        python open_page.py showcase/home.html     （主界面）
        python open_page.py showcase/index.html    （展厅）
  · 还打不开就加 --serve（走本地小服务，绕过 file:// 限制）：
        python open_page.py --serve room3d/index.html
  · 原因多半是 .html 的默认程序被改成了下载器/记事本，所以双击没反应。
    上面的方式直接点名 Chrome / Edge，不依赖系统关联。

【3D 小屋】
  · 双击“打开3D小屋.bat”，或在桌宠上右键 -> 去 3D 小屋，或主界面右上角「🏡 3D 小屋」。
  · 这是真的 3D 房间（不是贴图背景）：墙、床、书架、猫爬架、猫窝都是独立模型，
    宠物能走进去、绕开家具、走到床边和窗边。
  · 操作：
      - WASD 或 方向键 -> 走（方向跟着镜头）
      - 点地板       -> 自动寻路走过去（落点有光环）
      - 点床/球/猫爬架/书架/猫屋 -> 先走过去，再做对应动作
      - 拖动 / 滚轮   -> 旋转 / 缩放镜头（斜俯视）
      - 右下「互动」   -> 列出所有可互动的地方；「玩具」丢球或躲猫猫；「装扮」换头顶挂件
      - 右上 ☀/🌙     -> 白天 / 夜晚，⤾ 复位镜头，✦ 换一只伙伴
  · 不管它的时候，它会自己散步、坐下、转头看来看去，偶尔跑去窗边发呆。

【星穹展厅】
  · 双击“打开星穹展厅.bat”，或在桌宠上右键 -> 去星穹展厅，或在主界面舞台右下角点「星穹展厅」。
  · 星空下的法阵展台，宠物站在台上：
      - 按住鼠标左右拖动 -> 转盘带着宠物一起转身，能转到背面看
      - 滚轮 -> 拉近拉远
      - ← → 键 -> 左右转一档，1~5 -> 直接切到某一只
      - 双击宠物 -> 跳一下并说一句话
  · 底部一排头像是全部宠物，点一下就换；松开鼠标几秒后展台会自己慢慢转。
