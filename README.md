# 星宠语 · 桌面宠物（多宠物版）

把「星宠语」站点里的宠物做成活在 Windows 桌面上的小伙伴：会呼吸、会跑、会飞、会撑伞飘落、会趴睡冒泡泡，可以拖着放到屏幕任何位置，也能贴着窗口边框或屏幕边缘"探头"。

一只宠物 = 一个 **宠物包**（自己的图集、帧、台词）。当前已是 **九只**：星狐 / 奶糖（猫）/ 团团（羊）/ 布丁（泰迪）/ 可可（仓鼠）/ 美美（草莓熊）/ 泡泡（薄荷绿小熊）/ 牙牙（绿兔）/ 云汐（冰蓝小龙），右键菜单、2D 小窝、3D 小屋、星穹展厅里都能选到。

纯本地运行，不联网、不需要账号。Python 3 + tkinter + Pillow。

**对话交互**：鼠标移到宠物身上会浮出两颗液态玻璃图标按钮（房子 / 对话），不写文字，与角色严格同轴居中，移开自动收起。输入条平时不出现——只有点「对话」才弹出，居中贴在宠物正下方、跟着它走；点桌面空白或按 Esc 就收起。回车或点箭头发送，回复回到宠物身边的 3D 气泡。麦克风图标可开关语音朗读。

**右键菜单**同样换成了液态玻璃：自绘窗口（原生 `tk.Menu` 无法做磨砂），冷色折射 + 顶部天光 + 内外两道高光边 + 磨砂颗粒，与状态条共用一套 `_glass_pill` 材质；行悬停有玻璃高亮，带「今天心情如何」「换一只宠物」两处级联子菜单。菜单从宠物**外侧**展开（鼠标在右半边就往左开），不会糊住角色的脸；点菜单外或按 Esc 收起。

**真实对话（可选）**：默认使用本地上下文对话引擎（记住名字 / 偏好 / 近期聊天，按意图和情绪组织追问，离线可用）。要用真实大模型，在 `config.json` 里加：

```json
{
  "llm_base_url": "https://你的 OpenAI 兼容接口/v1",
  "llm_api_key": "你的 Key",
  "llm_model": "模型名"
}
```

也可用环境变量 `PET_LLM_BASE_URL` / `PET_LLM_API_KEY` / `PET_LLM_MODEL`。网络失败会自动回落到本地引擎，Key 不会写入日志。

**语音聊天（可选）**：宠物会用温柔女声念出回复；「说句话」也会朗读。语音由 edge-tts 在线合成并缓存到 `assets/voice_cache/`，重复台词不再联网；未安装 edge-tts 或断网时静默降级，气泡照常显示，桌宠其余功能不受影响。首次使用需 `py -3 -m pip install edge-tts`。

**情感陪伴（本地）**：
- **情绪记忆**：宠物有心情 / 亲昵两个数值，随互动增减；离线超过 6 小时会缓慢回到中性，久别重逢时它会主动打招呼。数据只在本地 `config.json`。
- **心情打卡**：右键 →「今天心情如何」选 5 档之一，可「看看近 7 天…」看趋势。记录只存本地 `mood_log.json`（不联网、不上传）。
- **舒缓引导**：聊天里说「焦虑 / 压力大 / 睡不着」会逐句引导 4-7-8 呼吸；说「5-4-3-2-1 / 锚定」会引导感官锚定。随时发新消息即可打断。
- **安全兜底**：识别到极端表述时停止娱乐化回复，弹出求助资源提示（全国心理援助热线 12356 等）。

> **说明**：星宠语是陪伴用的桌面宠物，**不是心理治疗工具，不提供诊断或医疗建议**。遇到心理危机请拨打心理援助热线或联系身边信任的人 / 专业机构。

## 快速开始

双击 `启动桌宠.bat`，启动 `config.json` 里记录的那只。指定某只：

```bat
py -3 pet_app.py --pet naitang
```

运行时右键宠物 → **换一只宠物** 选另一只（进程内直接换素材，不重启、不闪退；会自动记住，下次启动还是它）。

## 交互规则

| 操作 | 结果 |
| --- | --- |
| 清醒时单击身体 | 无反应（防打字误触） |
| 休眠时单击身体 | 唤醒 |
| 长按身体 0.35s | 进入拖拽跟随（不用双击） |
| 拖拽中向上抛、松手 | 撑降落伞：先膨胀张开，再缓缓飘落 |
| 双击桌面空白 | 走过去：目标在上方 → 扇翅飞；同高度 → 侧面跑；明显更低 → 直接开伞飘过去 |
| 拖到屏幕/窗口边缘 | 拖拽中 22px 内实时磁吸，松手 34px 内精确贴合（可站在标题栏/任务栏上沿） |
| 拖到屏幕左/右边缘 | 最多半个身体探出屏幕，脸和眼睛始终可见 |
| 闲置 60s | 趴睡，头顶持续冒出由小到大的云朵泡泡（最多 4 个） |
| 右键 | 弹出**液态玻璃菜单**（与状态条同一套材质）：说句话 / 睡一会儿 / 陪我走走 / **回到主界面（2D 小窝）** / **去星穹展厅** / **去 3D 小屋** / **宠物图鉴** / **换一只宠物** / 是否置顶 / 拜拜；悬停玻璃高亮，带子菜单，点菜单外或按 Esc 收起 |

## 新增一只宠物

1. 先出一张白底参考图 `source/ref/ref_white.png`（单只正面立绘，纯白无投影），再以它为 image-to-image 基准生成 3 张图集（同一角色才不会跑偏）：
   - `poses_2x2.png`：2×2，[站立, 趴睡, 被拎起（前爪上举）, 挥手]
   - `run_2x2.png`：2×2，**严格侧面朝右**的四足跑 4 拍（务必要求"尾巴在身后、不挡腿"）
   - `wing_2x2.png`：2×2，白羽翼收拢 → 肘部弯曲半展 → 全展 → 下压
2. 放到 `assets/pets/<新id>/source/`；`original.webp` 可由参考图直接抠出来（`build_assets.cutout`）。
   要进展厅再加一张转身四向 `turn_2x2.png`（背面 / 右后 3/4 / 右侧 / 右前 3/4），放到 `showcase/assets/turn/<新id>/`。
3. 在 `pets.json` 追加一条（照抄 naitang 的 `build` 段即可）。
4. `py -3 build_assets.py <新id>` → `py -3 gate_check.py <新id>` → `py -3 selftest.py`。
5. `py -3 tools/preview_frames.py <新id>` 看图验收。
6. 进网页：`py -3 showcase/tools/pack_textures.py`（补 `META` 里的文案）→ `cp showcase/data/pets.js room3d/data/pets.js`。

## 星宠语主界面（`showcase/home.html`）

桌宠右键「回到主界面」打开的就是这一页：顶部导航（首页 / 宠物图鉴 / 宠物小屋 / 好友社区）、中间宠物舞台、
右侧聊天 / 穿搭 / 喂食 / 状态面板，整体是**多巴胺配色 + 液态玻璃**（半透明白玻璃、彩色投影、背景四团色斑缓慢漂移）。

- **打开方式**：双击 `打开星宠语主界面.bat`，或桌宠右键「回到主界面」，或直接开 `showcase/home.html`。
- **八个场景**：花海晴空 / 云端书桌 / 暖阳卧室 / 樱花草原 / 月夜城堡 / 海盐沙滩 / 苔藓森林 / 星轨天台，
  都是程序化 SVG（白天、夜晚两套配色），不依赖任何外部图片，`file://` 直接跑。场景条横向排列，
  一屏放不下时用标题右侧的 ‹ › 翻页，选中的卡会自动滚进可视区。
- **换一只伙伴**：右上角按钮或「宠物图鉴 → 带回小屋」，会换立绘、名字、台词和场景描述。
- **右侧面板**：聊天（回车发送，宠物会按关键词回话）、穿搭（挂件叠加）、喂食（涨饱食度/心情）、状态（三条进度）。
- **存档**：场景、时段、挂件、三项状态存在浏览器 localStorage（`xingchongyu.house.v2`），换电脑不同步。
- **去展厅**：舞台右下角「✦ 星穹展厅」→ `index.html`。


## 3D 小屋（`room3d/`）

**不是把房间图当背景**：整间屋子由 244 个节点 / 228 个独立 mesh 组成（墙、地板、窗、床、书架、猫爬架、
猫窝、小圆桌、软窝、植物、玩具球…），每个家具是一个命名节点，导出成 `assets/room.gltf`，
前端用 GLTFLoader 加载，再按节点包围盒做碰撞与寻路。

| 能力 | 做法 |
| --- | --- |
| 自由移动 | WASD / 方向键，方向按**相机朝向**换算，宠物面朝移动方向 |
| 点击寻路 | 点地板 → 射线打到 y=0 平面 → 网格 A*（0.2m，39×29）→ 平滑路径 → 走过去，落点有光环标记 |
| 场景探索 | 窗边、床边、猫窝、软窝、猫爬架、小圆桌都有锚点，互动面板里可以直接点 |
| 家具互动 | 点床/球/猫爬架/书架/猫屋会**先走过去再执行**（睡觉、玩球、爬上去、钻小屋…） |
| 镜头 | 斜俯视 OrbitControls：拖动旋转（俯角限制 24°–65°）、滚轮缩放（3.4–10.5m）、禁平移 |
| 自主行为 | 空闲 3–7 秒随机：散步到可达点 / 原地转头观察 / 坐下 / 去窗边发呆 |
| 碰撞检测 | 家具 AABB + 0.13m 膨胀写进网格，宠物半径 0.155m，逐轴滑动（可贴墙走，不会穿模型） |

```
room3d/
├── index.html / style.css    页面与奶油风 UI（左上宠物卡、左下方向键、右下互动/玩具/装扮）
├── js/main.js                场景、光照、输入、互动、自主行为、主循环
├── js/room.js                加载 room.data.js，收集碰撞盒与可点击家具
├── js/nav.js                 网格 + A*（8 向不切角）+ 视线平滑
├── js/pet.js                 立牌宠物：billboard + 5 张转身图 + 镜像 = 8 向，走/坐/睡/跳/爬
├── app.bundle.js             esbuild 打包产物（普通 script，file:// 能跑）
├── assets/room.gltf          3D 房间（GLTF 2.0，含 base64 buffer）
├── assets/room.data.js       同一份模型的 JS 版，避开 file:// 的 fetch 限制
└── tools/build_room.mjs      程序化建模 + GLTFExporter 导出
```

**改房间**：编辑 `tools/build_room.mjs` 里的家具函数（坐标写在注释里），然后：

```bash
cd room3d
npm i three@0.160.0 && npm i -D esbuild   # 只有重构建时才需要（node_modules 已清掉）
node tools/build_room.mjs            # 重新导出 assets/room.gltf + room.data.js
./node_modules/.bin/esbuild js/main.js --bundle --format=iife --target=chrome110 --outfile=app.bundle.js
```

**加互动家具**：在 `js/room.js` 的 `INTERACTIVES` 里加一条（`anchor` 是走到的位置，`action` 见 `main.js::doAction`），
如果它要挡路，再把节点名加进 `COLLIDERS`。

菜单入口：桌宠右键「去 3D 小屋」，或双击 `打开3D小屋.bat`，或主界面右上角「🏡 3D 小屋」。

## 2D 小窝（`house2d/`）—— 现在的「主界面」

一间全景房间 + 六个近景场景 + 底部对话框。鼠标移到家具上会发光并浮出名字，点一下**真正切到那个
家具的近景插画**（不是把全景图放大），宠物跟着淡出、换位、淡入，对话框再升起说话。

| 交互 | 说明 |
| --- | --- |
| 悬停家具 | 奶油色柔光罩住家具 + 上方浮出「🐾 名字」胶囊标签 |
| 点击家具 | 交叉淡入切到该场景（`scene-*.webp`）+ 宠物淡出→换位→淡入 + 对话框升起说台词 |
| 六个场景 | 床 / 猫爬架 / 猫窝 / 桌子 / 书柜 / 窗边，各 3 句台词随机 |
| 点空白 / Esc | 淡回全景，宠物走回地毯中央，对话框换一句「接下来想去哪」 |
| 对话框 | 大白框 + 宠物半个身子趴在左下角 + 名字牌 + 三行台词 + 右下爪印按钮 |
| 说人话 | 点爪印展开输入框，或直接点台词下方的「选项气泡」，一问一答有来有回 |
| 左上交心 | 摸它，心情值 +6，对话也会跟着变黏人 |
| 右上 ⋯ | 星穹展厅 / 3D 小屋 / 宠物图鉴 / 换伙伴 / 说话 |
| 存档 | 宠物、心情、等级、你告诉它的名字存在 localStorage（`xingchongyu.nest.v2`） |

### 对话不是关键词糊弄

`app.js` 里是一张 30+ 条的意图表（`RULES`）+ 每个地点自己的语料（`SPOTS[].talk`）：

- **结合地点回答**：同样问「你在做什么」，在床边是「我在被子上滚来滚去」，在书柜前是「我在数书脊上的颜色」。
- **答完会追问**：每句回复都带 3 个**能被识别**的接话，比如它说「有点想吃小鱼干…你会给我吗？」，
  下面就是「给你一根小鱼干 / 我这儿没有诶 / 等我一下」，点哪个都有对应的下文（给了会加心情）。
- **会记事**：你跟它说「我叫小满」，它记进存档，之后会用「小满」叫你，道别时说「那…小满，早点回来」。
- **会带路**：说「带我去床边」「去窗边」，它先说一句「跟我来」，然后自己切到那个场景。
- **不复读**：同一句话问第二遍会换开场（「又问一次呀～」），问第三遍再换。
- **心情影响语气**：心情低于 30 时，回答前面会带「（有点没精神）」。

自测脚本跑过一遍：**132 个选项气泡全部能被规则接住，0 个掉进兜底回答**。

```
house2d/
├── index.html / style.css / app.js
└── assets/
    ├── room.webp              全景（1536x818，已裁掉底部水印）
    ├── scene/scene-bed.webp   六个近景（各约 70-95KB）
    └── source/                原始 PNG（重绘时改这里，但别直接引用）
```

**坐标怎么来的**：`SPOTS` 里 `x/y/w/h` 是**全景图上的百分比**（热区），`px/py/ph` 是**视口百分比**
（宠物在近景里的落脚点与高度）。全景用 `fitWorld()` 做成「按图片比例 cover 视口」的盒子，
所以热区百分比 = 图片百分比，换全景图只要重标一遍数字；近景是整屏 `cover`，宠物按视口定位，
换图后目测微调 `px/py` 即可。

调试参数：`?pet=3`（第几只）、`?spot=bed`（直接进场景）、`?lit=bed`（强制点亮标签）、
`?spots=1`（显示热区框）、`?fast=1`（跳过打字机）。

## 网页打不开怎么办

三个页面（主界面 / 展厅 / 3D 小屋）都是纯静态的，`file://` 直接双击就能跑。如果点了没反应、白屏、
或者变成下载文件，按顺序试：

1. **双击 `检查打开环境.bat`**：会列出项目里能找到的浏览器和三个页面的存在情况。
2. **用 `open_page.py` 打开**（它直接点名 Chrome / Edge，不走 `.html` 的系统关联）：

   ```bash
   python open_page.py room3d/index.html       # 3D 小屋
   python open_page.py showcase/home.html      # 主界面
   python open_page.py showcase/index.html     # 星穹展厅
   ```

3. **还是不行就用本地服务**（绕过浏览器对 `file://` 本地资源的限制）：

   ```bash
   python open_page.py --serve room3d/index.html
   ```

   会在 `127.0.0.1:8765` 起一个小服务再打开；关掉窗口后服务还在后台，重启电脑自动清掉。

常见根因：`.html` 的默认程序被装机软件改成了下载器 / 记事本 / 老 IE（所以「双击没反应」或「白屏」）。
`打开*.bat` 现在都走 `open_page.py`，不再依赖系统关联。

## 星穹展厅（`showcase/index.html`）

一个纯前端的 3D 展示厅：星空下把宠物摆在发光的法阵台上，**拖动可以看它转身**，滚轮缩放，12345 或点底部头像换宠。

- 打开方式：双击 `打开星穹展厅.bat`，或直接开 `showcase/index.html`（贴图是内嵌的，file:// 也能跑），
  也可以在桌宠右键菜单里点「去星穹展厅」；页面右上角「← 回主界面」可以回到小屋。
- 技术：three.js（本地 `vendor/three.min.js`，无 CDN 依赖）+ 程序化星空（三层视差 + 银河带 + 闪烁 shader + 流星）。
- **转身**：每只宠物有 5 个朝向（正面 / 右前 45° / 右侧 / 右后 135° / 背面），左侧是镜像复用，
  凑成 8 个朝向；转盘转到哪个角度就切到哪个朝向，靠近下一档时做 28% 区间的交叉淡入，
  所以正对角度是清晰的、快速拖动时才短暂叠化。

## 踩坑备忘

- **透明窗口**：用色键 + 不手动加 `WS_EX_LAYERED/TRANSPARENT`；alpha 边会染色，所以显示用"展平到键色"的 display 帧、逻辑用真值 alpha 帧。
- **隐形窗口测尺寸**：Tk 里 `deiconify()` 之前 `winfo_width()` 返回 1，必须先显示再测量。
- **AI 图集的格线**：很多图集用浅灰细线分格，会把每格白底围成封闭区域导致 flood fill 抠不进去 —— 切格时往内缩 3px。
- **序列缩放**：整段动作按序列中位 bbox 统一缩放；宽幅姿态（趴睡）要改成按宽度缩放，否则左右被裁。
- **投影**：正解是生成时要求"纯白无投影背景"。已经烤进画面的浅灰投影，**深色毛**的宠物可以用 `shadow_key`（内部孔洞会回填）；**奶白毛**的宠物千万别开，毛会被一起抠空。
- **共享伞面别带身体部件**：早期 `canopy.png` 是从星狐那张手绘伞上裁的，底部带进了星狐的耳朵。现在 `assets/shared/source/chute_raw.png` 是照星狐伞风格单独生成的「空伞」（无角色无耳朵），`tools/make_chute_rig.py` 抠图后用形态学开运算吃掉吊绳，只留伞面。
- **合成伞的版式照星狐实测走**：伞顶钉死在 `head_top - 128`，四帧里伞往下张开、吊绳随之变短（星狐 4 帧「伞顶到头顶」的跨度基本恒定）。反过来做（伞沿钉死、伞往上长）第一帧会像一顶扣在脑袋上的帽子。
- **吊绳从伞沿褶谷拉，不要按固定比例取列**：伞面最外侧那一列的最低点落在伞的「腰部」，从那里拉绳会像从伞侧横着支出来一根铁丝。`rope_anchors()` 在 5 个横带里各取伞沿最低点。
- **连接件拉长**：把伞和宠物之间的绳子拉长只能用局部纵向拉伸，横切伞面必留断层。
- **睡眠泡泡窗口**：固定尺寸画布、只换图；每帧 resize 透明窗口会闪黑框。
- **全局鼠标钩子**：受限环境里 `WH_MOUSE_LL` 可能收不到回调，运行时用 `GetAsyncKeyState` + `GetCursorPos` 轮询。
- **DPI**：启动即 `SetProcessDpiAwareness`，否则 125%/150% 缩放下坐标与截图对不上。
- **换宠物**：切换时写 `config.json` 后 `os.execv` 重启自己，比在进程内换整套帧干净。
- **睡眠/被拎起不能按高度归一**：这些姿态是"趴开"的，按 250 高填满会被整体放大一圈，看起来比醒着时大一号。
  现在改成以 idle 的内容**面积**为基准反算缩放（`normalize_scaled`），睡眠与待机视觉体量一致。
- **AI 原图自带地面投影**：脚边那摊近白/近灰的"影子"抠不掉，边界 flood fill 会停在渐变上。
  用 `clean_pad`（`pets.json` 里按宠物开）只删"中性白 + 扁平 + 位于画面下部 + 与透明区相邻"的连通块；
  奶白/暖白毛发饱和度更高，不会被误删——反过来用统一的"近白"规则会把毛边一起吃掉。
- **先缩放再展平**：`DISPLAY_SCALE` 生效时必须在 alpha 帧上缩放、再填键色；
  先展平再缩放，键色会和毛边混成脏边。
